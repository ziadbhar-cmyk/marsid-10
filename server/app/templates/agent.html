خطوات التركيب (مرة واحدة)
  1. نزّل حزمة الوكيل الجاهزة لهذا المشروع: تنزيل MarsadAgent.zip
  2. انسخها إلى الجهاز الذي فيه قاعدة البيانات وفك الضغط في C:\MarsadAgent
  3. افتح config.json وعدّل سطر الاتصال بقاعدة البيانات (نوعها: {{ DB_ENGINES.get(p.conn.engine, '') }}). الرابط والرمز السري معبّأين مسبقاً.
  4. شغّل setup_agent.bat كمسؤول (Run as administrator). يثبّت المتطلبات ويجرّب الاتصال ويسجل الوكيل ليشتغل تلقائياً مع تشغيل الجهاز.
  5. ارجع لهذه الصفحة. عندما يظهر "متصل" افتح مستكشف الجداول ثم ربط البيانات.
الأمان: أنشئ في قاعدة البيانات مستخدماً للقراءة فقط (مثال SQL Server في ملف README_AGENT). الوكيل يرفض أي أمر غير SELECT، ولا يفتح أي منفذ على جهاز المحل؛ هو من يتصل بالسيرفر عبر HTTPS فقط.
